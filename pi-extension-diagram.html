Skills → Extension

The same capabilities, now a tool the model can reach for.

A skill is a capability you invoke as a slash-command — one shot, on your say-so. The pi extension takes those same capabilities (html, html-diagram, html-plan) and surfaces them as tools the model can call itself, any time, mid-task, as often as the work needs.

The mapping

Each skill → its equivalent on-demand tool

Skill /skill:html Author a standalone HTML artifact
Tool html() Generate HTML on demand, mid-task
Skill /skill:html-diagram Render a spatial diagram
Tool html_diagram() Draw a diagram whenever it clarifies
Skill /skill:html-plan Lay out a structured plan view
Tool html_plan() Produce a plan artifact as the work evolves

Takeaway

Same capabilities — but the extension turns a user-triggered slash command into a tool the model can invoke anytime, mid-task and on repeat.
